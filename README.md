## The line

> The deadline was clearly labeled 'Friday'. I have read it 40,000 times since Monday — confidence was never the problem; the calendar was.

## About

A one-line excuse built on a calendar mix-up: the deadline was read obsessively — 40,000 times since Monday — so confidence was never the issue. The twist lands in the final clause: the calendar itself was the problem. The entrypoint in `main.py` writes this line, plus a trailing newline, to `/output/entry.txt`.
